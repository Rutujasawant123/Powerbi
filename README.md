# Management Sales Dashboard

## 📊 Project Overview

This project is a Management Sales Dashboard created using Microsoft Power BI.

The dashboard provides interactive visualizations and insights into sales performance, helping management understand key business metrics and trends.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset
- Data Visualization

## 📈 Key Features

- Sales performance analysis
- KPI tracking
- Interactive charts and visuals
- Sales trend analysis
- Management-focused insights

## 🎯 Objective

The objective of this project is to analyze sales data and present meaningful insights through an interactive Power BI dashboard.
